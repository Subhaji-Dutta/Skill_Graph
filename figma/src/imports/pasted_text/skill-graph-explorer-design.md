Design a modern SaaS-style web application called "Skill Graph Explorer".

The application demonstrates the power of a Graph Database (CognoDB/Neo4j) by helping developers explore skills, prerequisites, companies, and career paths through connected data.

Style:
- Modern, minimal, premium
- Similar quality to Linear, Vercel, GitHub, Stripe Dashboard, Notion
- Clean spacing using an 8px grid
- Soft shadows
- Rounded corners (16px)
- Glassmorphism only where appropriate
- Light theme
- Responsive desktop-first layout
- Blue (#2563EB) as primary color
- Neutral gray palette
- Inter font
- Plenty of white space
- Beautiful micro-interactions
- Professional UI suitable for a software company interview assignment
